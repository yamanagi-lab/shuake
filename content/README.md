# 正文文件格式说明

每一章是一个 `.txt` 文件，在 `toc.txt` 里登记后就会出现在目录中。正文由若干「段落块」组成，每个块以 `::` 开头的一行标明类型。

## 对照（双栏）

```
::对照
明智吾郎：
-日文第一句
-日文第二句
坂本竜司：日文台词
::译
明智吾郎：
-中文第一句
-中文第二句
坂本龙司：中文台词
```

- `::对照` 下写日文，`::译` 下写对应的中文。
- 「名字：台词」开始一个新的发言；以 `-` 开头的行是同一个人的下一句。
- 日文和中文按发言顺序一一对应，所以两边的发言人数要一致；每人的句数也一致时，网页会逐句对齐。
- 用（ ）整行括起来的是旁白或心理活动，例如 `（55：！）`。

## 逐行

```
::逐行
明智吾郎：日文台词
明智吾郎：中文台词
（只写在中文里的旁白）
明智吾郎：どうかした? | 你怎么了？
```

一行日文紧跟一行中文；也可以用 `|` 把日文和中文写在同一行。

## 选项

```
::选项 （该选项无差分）
> 日文选项 | 中文选项 | 1🎶
明智吾郎：日文回应
明智吾郎：中文回应
※ 只针对这个选项的短注释
> 日文选项 | 中文选项 | 无🎶
```

- 每个选项以 `>` 开头；第三项是好感度，写 `1🎶`、`2🎶` 或 `无🎶`，不写就不显示。
- 选项下面的回应按「逐行」的写法。
- `::选项` 后面的文字会作为这组选项的说明。

## SNS

```
::SNS 明智吾郎
-对方发来的日文 | 中文
55：55 的回复 | 中文
```

## 注释、小结、碎碎念

```
::注
术语：解释……（每行一段）

::小结
coop 结尾的日文介绍
对应的中文

::碎碎念 碎碎念环节（本栏含有个人向解读，请按需选择是否阅读）
1. 第一条
1. 第二条
> 引用内容（例如来自 Claude 的释义）
```

碎碎念在网页上默认折叠，读者自己点开。
